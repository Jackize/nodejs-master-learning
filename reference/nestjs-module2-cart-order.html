Cart → Order — ôn nhanh

Bài 09–13: giỏ, checkout + hold stock, webhook status, idempotency HTTP, HMAC.

Cart (09)

  • 1 cart / userId (ObjectId); JWT trên /cart
  • Add qua ProductsService.findById (soft-deleted → 404)
  • Snapshot name + unitPrice trên item

Checkout + inventory (10)

  • Mongo replica set bắt buộc cho multi-doc transaction
  • holdStock: stock >= qty + $inc: -qty → thiếu = 409
  • withTransaction: hold → create order pending_payment → clear cart

  • Bài 11: secret header (học flow)
  • Bài 13: x-payment-signature: t=…,v1=… HMAC trên rawBody + skew ~300s

Idempotency-Key (12)

  • Checkout bắt buộc header; unique (userId, key)
  • started → claim; completed + orderId → replay
  • Đang started → 409; checkout fail → xóa record (retry)
