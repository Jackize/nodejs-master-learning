Nest foundation — ShopStream

Cô đọng Bài 00–04: Compose, config fail-fast, module/DI, ValidationPipe.

Stack local

bash 
cd shopstream && docker compose up -d
cd api && npm run start:dev
curl -s http://localhost:3000/health

Config 12-factor

  • ConfigModule.forRoot({ validationSchema }) — Joi MONGODB_URI required
  • Thiếu env → Config validation error lúc start (fail fast)
  • config.getOrThrow('MONGODB_URI') cho Mongo

Feature module

MảnhVai trò

providersService / logic

ValidationPipe (global)

main.ts 
app.useGlobalPipes(new ValidationPipe({
  whitelist: true,
  forbidNonWhitelisted: true,
  transform: true,
}));

DTO = class + decorator (@IsString, @Min…). Field lạ → 400 khi forbid.
