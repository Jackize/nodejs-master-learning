Soft delete + pagination

Win: GET ?page&limit trả { data, meta }; DELETE ẩn sp (không xoá document); list không còn sp đã xoá; có index deletedAt_1_createdAt_-1.

⏱ ~50–70 phút · 🎯 Tự code — verify sandbox: 8 tests · pagination + soft-delete OK.

✍️ Tự làm

Không apply sẵn vào shopstream/. Đọc → tự sửa schema/service/controller/test → nộp bằng chứng.

🌉 Bắc cầu

Catalog đã lưu Mongo. Ecommerce hầu như không hard-delete product (đơn cũ, báo cáo). Soft-delete = gắn deletedAt. List lớn cần skip/limit + total, không trả cả collection.

💡 Soft-delete vs hard-delete

Hard-delete mất lịch sử / phá FK tinh thần (order line vẫn trỏ product). Soft-delete giữ audit; đánh đổi: mọi query “active” phải lọc deletedAt: null — quên một chỗ là “ma” hiện lại.

2. Query DTO phân trang

bash 
# Tự tạo file trong dto/
src/catalog/dto/list-products-query.dto.ts 
import { Type } from 'class-transformer';
import { IsInt, IsOptional, Max, Min } from 'class-validator';

export class ListProductsQueryDto {
  @IsOptional()
  @Type(() => Number) // query string → number
  @IsInt()
  @Min(1)
  page: number = 1;

  @IsOptional()
  @Type(() => Number)
  @IsInt()
  @Min(1)
  @Max(100)
  limit: number = 10;
}

3. Service: filter + skip/limit + softDelete

ý chính ProductsService 
async findAll(query: ListProductsQueryDto): Promise<PaginatedProducts> {
  const page = query.page ?? 1;
  const limit = query.limit ?? 10;
  const filter = { deletedAt: null };
  const [docs, total] = await Promise.all([
    this.productModel.find(filter).sort({ createdAt: -1 })
      .skip((page - 1) * limit).limit(limit).exec(),
    this.productModel.countDocuments(filter).exec(),
  ]);
  return {
    data: docs.map((d) => this.toResponse(d)),
    meta: { page, limit, total, totalPages: Math.ceil(total / limit) || 0 },
  };
}

async softDelete(id: string): Promise<void> {
  const doc = await this.productModel.findOneAndUpdate(
    { _id: id, deletedAt: null },
    { deletedAt: new Date() },
    { new: true },
  ).exec();
  if (!doc) throw new NotFoundException('Product not found');
}

// findById cũng phải: findOne({ _id, deletedAt: null }) + NotFoundException

Thêm type PaginatedProducts trong product.types.ts. create nên set deletedAt: null tường minh.

4. Controller

products.controller.ts 
@Get()
list(@Query() query: ListProductsQueryDto) {
  return this.productsService.findAll(query);
}

@Delete(':id')
async remove(@Param('id') id: string) {
  await this.productsService.softDelete(id);
  return { ok: true };
}

Q: Offset pagination (skip) yếu chỗ nào?
A: Deep page chậm + lệch khi insert đồng thời. Cursor/_id seek ổn định hơn ở scale lớn — Bài này dùng offset vì catalog MVP + dễ hiểu; biết trade-off là đủ phỏng vấn junior→mid.
