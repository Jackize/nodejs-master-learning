Auth JWT tối thiểu (buyer)

Win: POST /auth/register|login trả accessToken; GET /auth/me cần Bearer — không token → 401; sai password → 401.

⏱ ~60–90 phút · 🎯 Tự code — verify: @nestjs/jwt@11.0.2, bcrypt@6.0.0, 10 tests xanh.

✍️ Tự làm

Không pre-fill vào shopstream/. Catalog tạm thời vẫn public — bài này dựng Auth + JwtAuthGuard để Cart/Order (bài sau) reuse.

🌉 Bắc cầu

Cart/Order cần biết “ai” đang mua. JWT = stateless identity sau login. Nest: Passport JWT strategy + Guard — xem Nest Authentication và JWT.

💡 Vì sao hash password + secret trong env?

Lưu plaintext = thảm họa. bcrypt.hash chậm có chủ đích (chống brute-force). JWT_SECRET required trong Joi (Bài 01 mindset) — thiếu secret thì app không start.

4. AuthModule: register / login / JWT strategy / guard

FileVai trò
register.dto.ts / login.dto.ts@IsEmail + password MinLength(8)

auth.controller.tsPOST register|login, GET me + @UseGuards(JwtAuthGuard)
JwtModule.registerAsync — ý chính 
JwtModule.registerAsync({
  inject: [ConfigService],
  useFactory: (config: ConfigService) => ({
    secret: config.getOrThrow<string>('JWT_SECRET'),
    signOptions: {
      expiresIn: config.get<number>('JWT_EXPIRES_IN', 86400),
    },
  }),
}),
auth.service — login (ý chính) 
const user = await this.usersService.findByEmail(dto.email);
if (!user) throw new UnauthorizedException('Invalid credentials');
const ok = await bcrypt.compare(dto.password, user.passwordHash);
if (!ok) throw new UnauthorizedException('Invalid credentials');
// Không nói “email không tồn tại” vs “sai pass” — giảm user enumeration
return { accessToken: this.jwtService.sign({ sub: String(user._id), email: user.email }) };
GET /auth/me 
@UseGuards(JwtAuthGuard)
@Get('me')
me(@Req() req: { user: { userId: string; email: string } }) {
  return req.user;
}

Import AuthModule vào AppModule. Export JwtAuthGuard (+ Passport/Jwt nếu cần) từ AuthModule.

Góc phỏng vấn

Q: JWT vs session cookie?
A gọn: JWT stateless, dễ scale API; khó revoke sớm (cần denylist/TTL ngắn). Session lưu server, revoke dễ, cần sticky/store. Product API hay JWT (+ refresh sau này).
