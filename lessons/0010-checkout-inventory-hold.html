Checkout & inventory hold

Win: POST /orders/checkout (JWT) tạo Order pending_payment từ Cart, trừ stock atomic, xóa giỏ — thiếu hàng → 409 và rollback transaction.

⏱ ~90–120 phút · 🎯 Tự code — verify: Mongo replica set + session transaction (Nest + Mongoose docs).

✍️ Tự làm

Không pre-fill vào shopstream/. Bạn mở rộng Cart/Catalog + thêm OrdersModule. Bài 09 snapshot giá trên Cart → Order giữ nguyên snapshot đó.

🌉 Bắc cầu

Cart = ý định mua. Checkout = chốt: tạo Order + hold hàng (trừ stock) trước khi thanh toán. Không atomic → hai buyer cùng mua hết kho → oversell. Mongo multi-document transaction cần replica set — xem Mongoose Transactions và Nest MongoDB Sessions.

💡 Vì sao hold ngay lúc checkout?

Chỉ tạo Order rồi trừ stock lúc “paid” thì cửa sổ giữa hai bước bị oversell. Hold sớm = kho đã khóa cho order pending_payment. Trade-off: user bỏ thanh toán → phải release stock (Bài sau / job TTL). MVP: hold = $inc: { stock: -qty } kèm điều kiện stock >= qty.

1. Catalog — holdStock

products.service.ts — thêm 
async holdStock(
  productId: string,
  quantity: number,
  session?: ClientSession,
): Promise<void> {
  const updated = await this.productModel
    .findOneAndUpdate(
      {
        _id: productId,
        deletedAt: null,
        stock: { $gte: quantity }, // đủ hàng mới trừ
      },
      { $inc: { stock: -quantity } },
      { new: true, session },
    )
    .exec();
  if (!updated) {
    throw new ConflictException('Insufficient stock'); // 409
  }
}

orders.service — checkout (ý chính) 
async checkout(userId: string): Promise<OrderResponse> {
  const session = await this.connection.startSession();
  try {
    let orderDoc!: OrderDocument;
    await session.withTransaction(async () => {
      const items = await this.cartService.getItemsOrEmpty(userId, session);
      if (items.length === 0) {
        throw new BadRequestException('Cart is empty');
      }
      for (const item of items) {
        await this.productsService.holdStock(item.productId, item.quantity, session);
      }
      const total = items.reduce((a, i) => a + i.quantity * i.unitPrice, 0);
      const created = await this.orderModel.create(
        [{ userId: new Types.ObjectId(userId), items: /* map ObjectId */, total, status: OrderStatus.PendingPayment }],
        { session },
      );
      orderDoc = created[0];
      await this.cartService.clearItems(userId, session);
    });
    return this.toResponse(orderDoc);
  } finally {
    await session.endSession();
  }
}

Model.create([doc], { session }) — dạng mảng khi có session (Mongoose). Import OrdersModule vào AppModule.
