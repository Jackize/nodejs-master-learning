💡 Vì sao unit, chưa e2e đầy đủ?

Unit test Health + schema chạy <1s, không cần Docker — CI/local tight feedback. E2e với Mongo thật để dành khi có Catalog API. Theo Nest Testing: dùng Test.createTestingModule + mock provider (token connection qua getConnectionToken()).

1. Test Health — mock readyState

@InjectConnection() lấy token mặc định của Mongoose. Trong test, cung cấp object giả { readyState } thay vì Mongo thật.

src/health/health.controller.spec.ts (file mới) 
import { Test, TestingModule } from '@nestjs/testing';
import { getConnectionToken } from '@nestjs/mongoose';
import { HealthController } from './health.controller';

describe('HealthController', () => {
  async function createController(readyState: number) {
    const module: TestingModule = await Test.createTestingModule({
      controllers: [HealthController],
      providers: [
        {
          provide: getConnectionToken(), // token connection mặc định
          useValue: { readyState },
        },
      ],
    }).compile();
    return module.get(HealthController);
  }

  it('trả ok=true khi mongo connected (readyState=1)', async () => {
    const controller = await createController(1);
    await expect(controller.check()).resolves.toEqual({
      ok: true,
      mongo: 'up',
      service: 'shopstream-api',
    });
  });

  it('trả ok=false khi mongo chưa connected', async () => {
    const controller = await createController(0);
    await expect(controller.check()).resolves.toEqual({
      ok: false,
      mongo: 'down',
      service: 'shopstream-api',
    });
  });
});

2. Test schema Joi — không cần Nest bootstrap

Validate schema thuần: nhanh, rõ contract env. Đây là “bảo hiểm” cho Bài 01.

src/config/env.validation.spec.ts (file mới) 
import { envValidationSchema } from './env.validation';

describe('envValidationSchema', () => {
  it('pass khi có MONGODB_URI', () => {
    const { error, value } = envValidationSchema.validate({
      MONGODB_URI: 'mongodb://127.0.0.1:27017/shopstream',
    });
    expect(error).toBeUndefined();
    expect(value.PORT).toBe(3000); // default từ schema
  });

  it('fail khi thiếu MONGODB_URI', () => {
    const { error } = envValidationSchema.validate({ NODE_ENV: 'development' });
    expect(error).toBeDefined();
    expect(error?.message).toMatch(/MONGODB_URI/);
  });
});

Q: “Unit vs integration vs e2e?”
A gọn: Unit = 1 đơn vị + mock (nhanh, ổn định). Integration = vài lớp thật (vd Nest + Mongo testcontainer). E2E = HTTP full path. Kim tự tháp: nhiều unit, ít e2e đắt đỏ. Health unit mock readyState thuộc tầng unit.
