Webhook HMAC signature

Win: POST /webhooks/payment không còn so secret plaintext — verify header x-payment-signature: t=…,v1=… (HMAC-SHA256 trên raw body); body bị sửa → 401.

⏱ ~75–100 phút · 🎯 Tự code — tinh thần Stripe webhook signatures + Nest rawBody.

✍️ Tự làm

Không pre-fill vào shopstream/. Giữ logic paid/failed Bài 11; chỉ đổi lớp xác thực. Cheat-sheet Module 2: Cart → Order.

🌉 Bắc cầu

Bài 11: header secret tĩnh — ai biết secret là gọi được, và không chứng minh body nguyên vẹn. HMAC: provider ký timestamp + raw JSON; bạn tính lại bằng cùng secret. Sai 1 byte body → chữ ký lệch. Kafka sau này cũng hay ký/verify payload ở biên.

💡 Vì sao phải raw body?

JSON.parse rồi JSON.stringify lại có thể đổi khoảng trắng/thứ tự key → HMAC lệch dù “cùng object”. Stripe docs nhấn: verify trên bytes gốc. Nest: NestFactory.create(AppModule, { rawBody: true }) rồi đọc req.rawBody.

1. Bật rawBody

main.ts 
const app = await NestFactory.create(AppModule, { rawBody: true });

2. Helper verify (timing-safe)

orders/utils/payment-signature.ts — ý chính 
// Header: x-payment-signature: t=<unix>,v1=<hex>
// Signed: `${t}.${rawBodyUtf8}`
const expected = createHmac('sha256', secret)
  .update(`${t}.${rawBody.toString('utf8')}`)
  .digest('hex');

// So sánh độ dài + timingSafeEqual — tránh leak theo thời gian
if (a.length !== b.length || !timingSafeEqual(a, b)) {
  throw new Error('SIGNATURE_MISMATCH');
}

// |now - t| > 300s → TIMESTAMP_EXPIRED (chống replay thô)

5. Sanity (nộp) — curl ký bằng Node

bash 
cd shopstream/api && npm test && npm run build
# docker compose up -d mongo nếu Mongo down

# Sau checkout lấy ORDER_ID + Idempotency-Key như Bài 12
BODY=$(node -pe 'JSON.stringify({orderId:process.argv[1],result:"paid"})' "$ORDER_ID")
SIG=$(node -e '
const {createHmac}=require("crypto");
const secret=process.env.PAYMENT_WEBHOOK_SECRET;
const body=process.argv[1];
const t=Math.floor(Date.now()/1000);
const v1=createHmac("sha256",secret).update(t+"."+body).digest("hex");
console.log(`t=${t},v1=${v1}`);
' "$BODY")

# thiếu / sai chữ ký → 401
curl -s -w '\n%{http_code}\n' -X POST http://localhost:3000/webhooks/payment \

# hợp lệ → paid
curl -s -X POST http://localhost:3000/webhooks/payment \
  -H 'Content-Type: application/json' \
  -H "x-payment-signature: $SIG" \

# đổi result trong body giữ nguyên SIG → 401

Góc phỏng vấn

Q: Secret header vs HMAC signature?
A gọn: Secret chứng minh “biết khoá”; HMAC chứng minh thêm “payload không bị sửa” (và có thể gắn timestamp chống replay). Production webhook (Stripe) dùng signature + raw body.

🧠 Kiểm tra nhanh

Câu 1. Vì sao không JSON.stringify(req.body) rồi mới HMAC?
Câu 2. timingSafeEqual giúp gì?
Câu 3. Attacker đổi result trong body nhưng giữ chữ ký cũ?
✅ Checklist
  • rawBody: true trong bootstrap
  • Header x-payment-signature dạng t=…,v1=…
  • timingSafeEqual + skew timestamp ~300s
  • Sai/thiếu chữ ký → 401; body sửa → 401
  • Chữ ký đúng → paid/failed như Bài 11
  • npm test xanh (kèm test helper)
