💡 Vì sao index ngay, không “để sau”?

Catalog sẽ list/filter theo tên và còn hàng+giá. Không index → COLLSCAN khi data lớn. Index sai/thừa cũng hại write — chỉ tạo index khớp query thật sự sẽ dùng.

1. Schema + index

bash 
mkdir -p src/catalog/schemas
src/catalog/schemas/product.schema.ts (tự tạo) 
import { Prop, Schema, SchemaFactory } from '@nestjs/mongoose';
import { HydratedDocument } from 'mongoose';

export type ProductDocument = HydratedDocument<Product>;

@Schema({ timestamps: true, collection: 'products' })
export class Product {
  @Prop({ required: true, trim: true })
  name!: string;

  @Prop({ required: true, min: 0 })
  price!: number;

  @Prop({ required: true, min: 0 })
  stock!: number;
}

export const ProductSchema = SchemaFactory.createForClass(Product);

// Sau createForClass — compound/index phụ (docs Nest/Mongoose)
ProductSchema.index({ name: 1 });
ProductSchema.index({ stock: 1, price: 1 });

2. Đăng ký model trong CatalogModule

src/catalog/catalog.module.ts 
import { MongooseModule } from '@nestjs/mongoose';
import { Product, ProductSchema } from './schemas/product.schema';

@Module({
  imports: [
    MongooseModule.forFeature([
      { name: Product.name, schema: ProductSchema },
    ]),
  ],
  controllers: [ProductsController],
  providers: [ProductsService],
  exports: [ProductsService], // đủ cho Cart; đừng export thừa nếu chưa cần
})
export class CatalogModule {}

3. Service: bỏ Map, inject Model

ý chính — ProductsService 
constructor(
  @InjectModel(Product.name)
  private readonly productModel: Model<ProductDocument>,
) {}

// Map _id → id cho API ổn định
private toResponse(doc: ProductDocument) {
  return {
    id: String(doc._id),
    name: doc.name,
    price: doc.price,
    stock: doc.stock,
  };
}

async findAll() {
  const docs = await this.productModel.find().sort({ createdAt: -1 }).exec();
  return docs.map((d) => this.toResponse(d));
}

async create(input: CreateProductDto) {
  const doc = await this.productModel.create({ ...input });
  return this.toResponse(doc);
}

Controller gọi service async như cũ (return this.productsService.create(body) — Nest await Promise).

Góc phỏng vấn

Q: Index nào cho “list sản phẩm còn hàng, sort giá tăng”?
A gọn: Compound { stock: 1, price: 1 } (hoặc partial index stock>0). Equality/range trái → sort phải theo thứ tự prefix của compound index. Đừng index mọi field “cho chắc”.
