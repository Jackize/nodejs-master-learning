Idempotent Kafka consumer

Win: cùng orderId bị deliver 2 lần (at-least-once) → side-effect notify chỉ chạy 1 lần; lần 2 log SKIP duplicate. Dùng Mongo unique index “claim” — bắc cầu từ Idempotency-Key (Bài 12).

⏱ ~90–120 phút · 🎯 Tự code · đã verify claim-first + E11000 trên Mongo RS · docs: Nest Kafka · at-least-once semantics.

✍️ Tự làm

Không pre-fill. Hybrid + @EventPattern Bài 17 giữ nguyên — bạn đổi NotifyService thành async + store đã xử lý. Retry/DLQ → bài sau. Cheat-sheet Module 3 (Kafka) đi kèm mốc 5 bài.

🌉 Bắc cầu

Bài 12: HTTP Idempotency-Key + unique (userId,key) → retry không tạo order 2 lần. Bài 15–17: Kafka at-least-once (crash trước commit offset / rebalance) → cùng message có thể vào handler lại. Cùng ý tưởng: ghi nhận đã xử lý trước/kèm side-effect.

💡 Claim-first (chọn cho notify)

1. insert { consumer, orderId } với unique index.
2. Thành công → mới gửi notify (log).
3. E11000 → đã claim rồi → SKIP, không notify lại.

Trade-off: crash sau insert, trước notify → có thể mất 1 lần gửi (at-most-once side-effect). Ngược lại “notify rồi mới insert” → dễ gửi trùng. Email/SMS thường ưu tiên không spam → claim-first. Nói rõ khi phỏng vấn.

2. NotifyService — claim rồi mới notify

src/notify/notify.service.ts — nguyên hướng 
import { Injectable, Logger } from '@nestjs/common';
import { ConfigService } from '@nestjs/config';
import { InjectModel } from '@nestjs/mongoose';
import { Model } from 'mongoose';
import { OrderPaidEvent } from './dto/order-paid.event';
import {
  ProcessedEvent,
  ProcessedEventDocument,
} from './schemas/processed-event.schema';

@Injectable()
export class NotifyService {
  private readonly logger = new Logger(NotifyService.name);
  private readonly recent: OrderPaidEvent[] = [];
  private readonly maxRecent = 20;
  private processedCount = 0;
  private skippedCount = 0;

  constructor(
    @InjectModel(ProcessedEvent.name)
    private readonly processedModel: Model<ProcessedEventDocument>,
    private readonly config: ConfigService,
  ) {}

  private consumerName(): string {
    // Dùng group id logic (không cần suffix -server) — ổn định qua restart
    return this.config.getOrThrow<string>('KAFKA_GROUP_ID');
  }

  async handleOrderPaid(event: OrderPaidEvent): Promise<{ status: 'processed' | 'skipped' }> {
    try {
      await this.processedModel.create({
        consumer: this.consumerName(),
        orderId: event.orderId,
        paidAt: event.paidAt,
      });
    } catch (error: unknown) {
      if ((error as { code?: number }).code === 11000) {
        this.skippedCount += 1;
        this.logger.log(`SKIP duplicate order.paid orderId=${event.orderId}`);
        return { status: 'skipped' };
      }
      throw error;
    }

    // Side-effect chỉ chạy sau khi claim thành công
    this.logger.log(
      `NOTIFY order.paid orderId=${event.orderId} userId=${event.userId} total=${event.total}`,
    );
    this.recent.unshift(event);
    if (this.recent.length > this.maxRecent) this.recent.pop();
    this.processedCount += 1;
    return { status: 'processed' };
  }

  getRecent(): OrderPaidEvent[] {
    return [...this.recent];
  }

  getStats() {
    return {
      processed: this.processedCount,
      skipped: this.skippedCount,
      recentCount: this.recent.length,
    };
  }
}

3. Controller — await + stats

notify.controller.ts — chỗ đổi 
@Get('stats')
stats() {
  return this.notifyService.getStats();
}

@EventPattern(ORDER_PAID_TOPIC)
async handleOrderPaid(
  @Payload() payload: OrderPaidEvent,
  @Ctx() context: KafkaContext,
): Promise<void> {
  // ... debug log key/partition như Bài 17
  if (!payload?.orderId) {
    this.logger.warn('Skip order.paid — thiếu orderId');
    return;
  }
  await this.notifyService.handleOrderPaid(payload);
}
Handler phải async/await

Nếu không await claim, Nest có thể commit offset trước khi Mongo xong → mất an toàn. Trả về Promise để framework chờ handler hoàn tất.

4. Unit test

notify.service.spec.ts — ý chính 
const event = {
  orderId: 'o1',
  userId: 'u1',
  total: 10,
  status: 'paid',
  paidAt: '2026-01-01T00:00:00.000Z',
};

it('lần 1 processed, lần 2 skipped', async () => {
  const processedModel = {
    create: jest
      .fn()
      .mockResolvedValueOnce({})
      .mockRejectedValueOnce(Object.assign(new Error('E11000'), { code: 11000 })),
  };
  const config = {
    getOrThrow: jest.fn().mockReturnValue('shopstream-notify-v1'),
  };
  const svc = new NotifyService(processedModel as any, config as any);

  await expect(svc.handleOrderPaid(event)).resolves.toEqual({ status: 'processed' });
  await expect(svc.handleOrderPaid(event)).resolves.toEqual({ status: 'skipped' });
  expect(svc.getRecent()).toHaveLength(1);
  expect(svc.getStats()).toEqual({ processed: 1, skipped: 1, recentCount: 1 });
});
