Cart model & add/remove

Win: 1 cart / user (JWT); GET /cart, POST /cart/items, DELETE /cart/items/:productId; soft-deleted product → 404 qua Catalog.

⏱ ~75–100 phút · 🎯 Tự code — verify: guard 401, snapshot giá, ObjectId query, npm test xanh.

✍️ Tự làm

Không pre-fill vào shopstream/. Dùng lại JwtAuthGuard (export từ Auth) + ProductsService (export từ Catalog). Nhắc T1 Bài 08: Cart không tự đọc deletedAt.

🌉 Bắc cầu

Module 1 = catalog + identity. Module 2 = “ai đang giữ gì trong giỏ” trước checkout. Cart gắn userId từ JWT; item lấy truth từ Catalog rồi snapshot name/price — giá catalog đổi sau vẫn giữ giá lúc add (checkout Bài 10 sẽ cần).

💡 Vì sao 1 document cart / user?

MVP: đọc/ghi đơn giản, unique index userId. Sau có thể tách “cart line” collection nếu cần query nặng — giờ chưa cần. Race hai request cùng tạo cart → E11000: xử lý bằng query đúng ObjectId + (tuỳ chọn) catch duplicate → find lại.

@Schema({ _id: false })

  productId!: Types.ObjectId;

@Schema({ timestamps: true, collection: 'carts' })
export class Cart {
  @Prop({ type: Types.ObjectId, ref: 'User', required: true, unique: true })
  userId!: Types.ObjectId;

  @Prop({ type: [CartItemSchema], default: [] })
  items!: CartItem[];
}

4. Service — Catalog gate + ObjectId trap

⚠️ Bug hay gặp (đã verify)

findOne({ userId: string }) có thể không match document lưu ObjectId → service tưởng chưa có cart → create → E11000 duplicate key trên userId_1 → HTTP 500. Luôn query/create bằng new Types.ObjectId(userId).

cart.service — ý chính 
private async getOrCreate(userId: string): Promise<CartDocument> {
  const uid = new Types.ObjectId(userId);
  let cart = await this.cartModel.findOne({ userId: uid }).exec();
  if (!cart) {
    cart = await this.cartModel.create({ userId: uid, items: [] });
  }
  return cart;
}

async addItem(userId: string, dto: AddCartItemDto) {
  // T1: Catalog quyết định “còn bán” — throw NotFound nếu soft-deleted
  const product = await this.productsService.findById(dto.productId);
  const cart = await this.getOrCreate(userId);
  const existing = cart.items.find((i) => String(i.productId) === dto.productId);
  if (existing) {
    existing.quantity += dto.quantity;
  } else {
    cart.items.push({
      productId: new Types.ObjectId(dto.productId),
      quantity: dto.quantity,
      name: product.name,
      unitPrice: product.price,
    });
  }
  await cart.save();
  return this.toResponse(cart);
}

removeItem: filter bỏ theo productId; nếu không đổi length → NotFoundException('Item not in cart'). Response map ObjectId → string (id, userId, productId).

5. Controller — JWT trên cả /cart

cart.controller.ts 
@Controller('cart')
@UseGuards(JwtAuthGuard)
export class CartController {
  @Get()
  get(@Req() req: { user: { userId: string } }) {
    return this.cartService.getCart(req.user.userId);
  }

  @Post('items')
  add(@Req() req: { user: { userId: string } }, @Body() dto: AddCartItemDto) {
    return this.cartService.addItem(req.user.userId, dto);
  }

  @Delete('items/:productId')
  remove(@Req() req: { user: { userId: string } }, @Param('productId') productId: string) {
    return this.cartService.removeItem(req.user.userId, productId);
  }
}

Bài 08 T2: per-controller OK cho app nhỏ; nhớ: global + @Public() là default-deny — ít quên hơn khi thêm route mới.

Góc phỏng vấn

Q: Giỏ lưu giá hiện tại hay snapshot?
A gọn: Snapshot lúc add (hoặc lúc checkout) — tránh user bất ngờ khi catalog đổi giá giữa session. Trade-off: giá cũ có thể lệch policy marketing; nhiều shop reprice ở checkout và báo user.
