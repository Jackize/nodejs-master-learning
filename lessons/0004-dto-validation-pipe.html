🌉 Bắc cầu từ Bài 03

Catalog đang nhận mọi JSON (kể cả name: 1). Product API cần hợp đồng input rõ. Nest dùng DTO class + ValidationPipe — xem Nest Validation.

💡 Pipe toàn cục vs validate trong service

Validate ở biên HTTP (pipe) → service nhận data đã sạch, ít if/throw lặp. whitelist + forbidNonWhitelisted: field lạ bị từ chối thay vì lặng lẽ ghi vào DB sau này (mass assignment).

2. Tạo DTO

bash 
mkdir -p src/catalog/dto
src/catalog/dto/create-product.dto.ts (tự tạo) 
import { IsInt, IsNumber, IsString, Min, MinLength } from 'class-validator';

export class CreateProductDto {
  @IsString()
  @MinLength(1)
  name!: string;

  @IsNumber()
  @Min(0)
  price!: number;

  @IsInt()
  @Min(0)
  stock!: number;
}

Đổi controller/service: dùng CreateProductDto thay CreateProductInput. Có thể xoá class cũ trong product.types.ts, giữ type Product.

3. Bật ValidationPipe global trong main.ts

src/main.ts — thêm useGlobalPipes 
import { ValidationPipe } from '@nestjs/common';
// ...
const app = await NestFactory.create(AppModule);

app.useGlobalPipes(
  new ValidationPipe({
    whitelist: true,              // bỏ field không có decorator
    forbidNonWhitelisted: true,  // field lạ → 400
    transform: true,               // plain object → instance DTO
    transformOptions: { enableImplicitConversion: true },
  }),
);

4. Error shape thống nhất (filter)

Validation mặc định của Nest đã trả 400, nhưng shape hơi “thô”. Filter nhỏ giúp mọi HttpException cùng format — tiện frontend và phỏng vấn.

bash 
mkdir -p src/common/filters
src/common/filters/http-exception.filter.ts (tự tạo) 
import {
  ArgumentsHost, Catch, ExceptionFilter, HttpException, HttpStatus,
} from '@nestjs/common';
import { Response } from 'express';

@Catch(HttpException)
export class HttpExceptionFilter implements ExceptionFilter {
  catch(exception: HttpException, host: ArgumentsHost) {
    const res = host.switchToHttp().getResponse<Response>();
    const status = exception.getStatus();
    const body = exception.getResponse();
    const message =
      typeof body === 'string'
        ? body
        : ((body as { message?: string | string[] }).message ?? exception.message);

    res.status(status).json({
      statusCode: status,
      error: HttpStatus[status] ?? 'Error',
      message,
      timestamp: new Date().toISOString(),
    });
  }
}
src/main.ts — đăng ký filter 
import { HttpExceptionFilter } from './common/filters/http-exception.filter';
// sau useGlobalPipes:
app.useGlobalFilters(new HttpExceptionFilter());

Q: whitelist vs forbidNonWhitelisted?
A: whitelist = im lặng bỏ field thừa; forbid = 400 nếu có field thừa. API public thường forbid để client biết contract; nội bộ đôi khi chỉ whitelist.
